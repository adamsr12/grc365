HTML to PDF

Section 1: Description

The JavaScript library HTML to PDF enables you to add a button to your page that, when pressed, will download the page as a graphic PDF. Being a graphic, unfortunately the downloaded PDF is not searchable or editable.

Also the HTML page may not contain any images because these will cause the JavaScript library to crash. Thus the library is best suited to text-only documents, such as business or informational documents.

Section 2: Conclusion

By forcing the canvas scale elements or configuring page-break directives to avoid splitting, html2pdf safely binds all visible document data into one page.

To fit into one page, this sample document is sized to half-page or 5.5 inches wide.
