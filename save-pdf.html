HTML to PDF

Section 1: Description

The JavaScript library “HTML 2 PDF” enables you to add a button to your page that, when pressed, will download the page as a graphic PDF. Being a graphic, unfortunately the downloaded PDF is not searchable or editable.

Also the HTML page may not contain any images, which will cause the JavaScript to crash. Thus the library is best suited to text-only documents, such as business or informational documents or, as in the example below, enabling readers to save form data.
